四、总结
--------

RxStudy 是一个功能完整的 App，使用传统的 RxSwift 响应式编程范式，依赖丰富（约27个），
适合复杂的 UIKit 开发和需要精细控制界面的场景。

SwiftUIStudy 是一个轻量级的 SwiftUI 探索项目，使用现代的 async/await 异步编程，
依赖精简（仅7个），专注于 SwiftUI 本身的学习和快速开发。

SwiftUIStudy 可以看作是 RxStudy 的 SwiftUI 简化版本，去除了 RxSwift 生态，
使用 SwiftUI 原生 API 替代大部分功能。
