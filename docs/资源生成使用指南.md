# SwiftGen 资源使用指南

本项目统一使用 SwiftGen，R.swift 已移除。完整入门流程见 [新手手册](工程生成新手实操手册.md#准备工具)。

## 生成资源代码

在任一构建方式的项目根目录执行：

```sh
bash scripts/swiftgen.sh
```

输入与输出由根目录的 swiftgen.yml 定义：

| 输入 | 输出与用途 |
| --- | --- |
| `Shared/Resources/Assets.xcassets` | `Shared/Generated/Assets+SwiftGen.swift`，提供 Asset |
| `RxStudy/zh-Hans.lproj/Localizable.strings` | `Shared/Generated/Strings+SwiftGen.swift`，提供 L10n |

当前中文字符串作为模板输入；生成代码不等于将所有语言资源打包到 Target，资源归属仍由工程配置控制。当前未启用字体生成；脚本中的字体提示不是现有输出文件。

## 日常使用

UIKit 的现有访问示例：

```swift
let image = Asset.back.image
```

新增图片后先生成再编译。生成文件中查看实际名称，不手工编辑生成代码。新增资源目录时参照 [共享资源配置示例](配置示例/工程配置示例.md#4-给两个-target-加入共享资源)。

首次 Tuist 生成工程前必须先运行 SwiftGen，使生成文件能够被 sources glob 扫描。生成目录不提交 Git；新机器需要安装工具并生成。

## Xcode 报未安装

先检查终端能否找到 SwiftGen。脚本已经补充 `/opt/homebrew/bin` 与 `/usr/local/bin`，避免 Xcode 的精简 PATH 找不到 Homebrew 安装。如果工具确实缺失，执行 `brew install swiftgen`。更多情况见 [排错指南](编译问题排查指南.md#1-工具找不到)。

官方资料：[SwiftGen 安装与使用](https://github.com/SwiftGen/SwiftGen#installation)。
